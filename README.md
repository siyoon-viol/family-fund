# 우리집 공금통장

가족 7명이 함께 쓰는 공금 장부입니다.

- **화면**: GitHub Pages (`index.html`)
- **데이터**: 구글 시트. 모든 기록이 시트에 남기 때문에 이 페이지가 없어져도 장부는 그대로 남습니다.

## 기능

- 현재 잔액, 이번 달 입금·출금, 회비 낸 인원
- 통장 형식의 거래내역(날짜, 적요, 찾으신 금액, 맡기신 금액, 잔액)과 CSV 내려받기
- 회비 현황표(구성원 × 최근 6개월). 미납 칸을 누르면 바로 기록할 수 있습니다.
- 최근 6개월 입출금과 지출 분류 통계

## 처음 설치 (관리자 1명이 한 번만)

### 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new)에서 새 시트를 만들고 이름을 `우리집 공금통장`으로 바꿉니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기의 `Code.gs` 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣습니다.
4. 맨 위 `PASSCODE` 값을 가족끼리 쓸 비밀번호로 바꾸고 저장합니다.
   > 이 비밀번호는 구글 계정 안에만 두세요. GitHub 저장소에는 올리지 않습니다.

### 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. **실행 사용자: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정합니다.
4. **배포**를 누르고 권한 요청을 허용합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 됩니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 3. 연결하기

1. 공금통장 페이지를 열고 웹 앱 URL과 비밀번호를 입력합니다.
2. **설정** 탭에서 가족 7명의 이름과 1인당 월 회비를 저장합니다.
3. **설정 → 가족 초대 링크 복사**로 만든 링크를 가족 단톡방에 보내고, 비밀번호는 따로 알려 줍니다.

## 가족이 쓰는 법

초대 링크를 열고 비밀번호를 한 번만 입력하면 그 기기에서 기억합니다. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 알아 둘 점

- 저장소와 페이지 주소는 공개되어 있지만, 비밀번호가 없으면 장부를 볼 수도 쓸 수도 없습니다.
- 비밀번호를 바꾸려면 `Code.gs`의 `PASSCODE`를 고친 뒤 **배포 → 배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포합니다. 같은 URL이 유지됩니다.
- 시트를 직접 고쳐도 됩니다. 단, `거래내역` 시트의 숨겨진 `id` 열은 지우지 마세요.
- 백업이 필요하면 구글 시트에서 **파일 → 사본 만들기**를 하면 됩니다.
